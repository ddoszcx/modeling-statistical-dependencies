# 📊 Моделирование статистических зависимостей

Репозиторий содержит материалы, практические работы, домашние задания и самостоятельные исследования по курсу «Моделирование статистических зависимостей» (эконометрика, регрессионный анализ, статистическое моделирование в Python).

---

## 🗂 Структура репозитория

| Раздел | Описание | Основные технологии / темы |
| :--- | :--- | :--- |
| [**`дз 1/`**](./дз%201/) | Оценка эффективности биотехнологических препаратов (ANOVA) | Однофакторный дисперсионный анализ, F-критерий Фишера, гипотезы, SciPy |
| [**`дз 2/`**](./дз%202/) | Моделирование сбережений домохозяйств на микроданных Росстата | Парная/множественная линейная регрессия, лог-модель эластичности, $t$-тесты, $F$-тест, Statsmodels |
| [**`практика 2 /`**](./практика%202%20/) | Расчёт и анализ метрик качества регрессионных моделей | MSE, RMSE, MAE, $R^2$, MSLE, RMSLE, AIC, BIC, Scikit-learn |
| [**`самостоятельная 3/`**](./самостоятельная%203/) | Борьба с мультиколлинеарностью и регуляризация моделей | Анализ матрицы корреляций, МНК, Ridge (L2), Lasso (L1 отбор признаков) |

---

## 🛠 Стек технологий

- **Язык программирования:** Python 3.10+
- **Анализ данных и вычисления:** `pandas`, `numpy`, `scipy`
- **Эконометрика и машинное обучение:** `statsmodels`, `scikit-learn`
- **Визуализация:** `matplotlib`, `seaborn`
- **Среда разработки:** Jupyter Notebook (`.ipynb`)
