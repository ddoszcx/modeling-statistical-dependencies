# 🧪 Домашнее задание 1: Дисперсионный анализ (ANOVA)

## 📌 Описание
Исследование посвящено оценке защитного эффекта биопрепарата-фиторегулятора (гиббереллина) различной концентрации против вирусного заболевания растений (морщинистой мозаики картофеля).

## 🎯 Основные задачи
1. Формирование структуры выборки по вариантам концентраций (контроль, 0.0001%, 0.0005%, 0.001%).
2. Проведение однофакторного дисперсионного анализа (One-way ANOVA).
3. Проверка статистических гипотез об отсутствии различий между группами с помощью F-критерия Фишера на уровне доверия 99% ($\alpha = 0.01$).
4. Определение оптимальной дозировки препарата, обеспечивающей максимальное подавление фитопатогена.

## 📁 Содержимое папки
- `practies1.ipynb` — Jupyter Notebook с расчётами, визуализацией распределений и статистическими выводами.
- `ДЗ_Семинара_1_Дисперсионный_анализ_данных_эксперимента.pdf` — методические указания и исходная постановка задачи.
