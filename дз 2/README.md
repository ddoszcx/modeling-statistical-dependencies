# 🏠 Домашнее задание 2: Эконометрическое моделирование сбережений домохозяйств

## 📌 Описание
Комплексный эконометрический анализ формирования сбережений домохозяйств (`rsber`) на основе микроданных Выборочного наблюдения доходов населения и участия в социальных программах (Росстат, 2023 год) по Московскому региону (код `ter = 45`).

## 🎯 Основные задачи
1. **Первичный анализ и фильтрация:** фильтрация выборки, удаление выбросов и аномалий, описательная статистика.
2. **Парная регрессия:** моделирование зависимости сбережений от денежного дохода домохозяйства (`doxodn`).
3. **Множественная регрессия:** включение дополнительных факторов (число детей `chdet`, состав семьи), оценка коэффициентов МНК, проверка условий Гаусса-Маркова.
4. **Проверка гипотез:** 
   - $t$-тесты Стьюдента на статистическую значимость отдельных факторов;
   - $F$-тест Фишера на общую адекватность регрессионной модели.
5. **Степенная модель (логарифмическая спецификация):** расчет эластичностей сбережений по доходу ($\ln(y) = \beta_0 + \beta_1 \ln(x) + \dots$), содержательная экономическая интерпретация.

## 📁 Содержимое папки
- `homework.ipynb` — ноутбук с кодом очистки данных, построения регрессий и визуализации.
- `Объяснение_заданий_3_и_6.md` — подробное математическое и теоретическое обоснование $t$-тестов и степенной лог-модели эластичностей.
- `Доходы домохозяйств_2023.xlsx` — исходный массив микроданных Росстата.
