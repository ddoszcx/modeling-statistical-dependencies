# 📈 Практическая работа 2: Метрики качества регрессионных моделей

## 📌 Описание
Практическая реализация математических формул и расчет метрик оценки точности и адекватности моделей линейной регрессии на языке Python.

## 🎯 Реализованные метрики
- **MSE** (Mean Squared Error) — среднеквадратичная ошибка.
- **RMSE** (Root Mean Squared Error) — корень из среднеквадратичной ошибки.
- **MAE** (Mean Absolute Error) — средняя абсолютная ошибка.
- **$R^2$** (Коэффициент детерминации) — доля объясненной моделью дисперсии.
- **MSLE / RMSLE** — логарифмические ошибки (устойчивы к выбросам при мультипликативном масштабе).
- **AIC** (Информационный критерий Акаике) и **BIC** (Байесовский информационный критерий) — критерии сравнения моделей с штрафом за избыточное число параметров.

## 📁 Содержимое папки
