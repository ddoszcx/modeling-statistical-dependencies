# 🔬 Самостоятельная работа 3: Мультиколлинеарность и регуляризация (Ridge & Lasso)

## 📌 Описание
Исследование проблемы сильной мультиколлинеарности в многомерных данных, её негативного влияния на метод наименьших квадратов (МНК) и способов решения с помощью методов регуляризации $L_1$ и $L_2$.

## 🎯 Ключевые этапы исследования
1. **Диагностика мультиколлинеарности:** анализ сильной связи между признаками (например, корреляция между $x_1$ и $x_3$ достигает 0.98).
2. **Оценка классическим МНК:** демонстрация раздувания дисперсии и контринтуитивных весов (коэффициент при $x_2$ искажается до $-18.38$).
3. **Ridge-регрессия (L2-регуляризация):**
   - Формула: $\hat{\beta}_{\text{ridge}} = (X^T X + \alpha I)^{-1} X^T y$.
   - Стягивание коэффициентов к нулю, устранение нестабильности матрицы и снижение чувствительности к шуму.
4. **Lasso-регрессия (L1-регуляризация):**
   - Автоматический отбор наиболее информативных признаков за счет зануления избыточных ($x_2, x_3, x_5$).
   - Выявление ключевых детерминант целевой переменной ($x_1$ и $x_4$).

## 📁 Содержимое папки
- `само.ipynb` — Jupyter Notebook с реализацией аналитического МНК, Ridge через матричные операции и Lasso через `sklearn`.
- `data.csv` — датасет с признаками ($x_1 \dots x_5$) и зависимой переменной $y$.
